This repository is my individual CodeShack Week 1 task. It documents Git fundamentals and practical command-line workflows.

What I Am Learning

- Git repository initialization and cloning
- Staging and committing changes
- Viewing history and differences
- Branching and collaboration
- Pushing and pulling changes from GitHub

Files

- "README.md" — Project overview and instructions.
- "git-notes.md" — Git commands with examples.

Workflow

1. Create or clone a repository.
2. Create a feature branch.
3. Make changes and inspect them.
4. Stage and commit changes.
5. Push the branch to GitHub.
6. Review and merge changes through a pull request when appropriate.
